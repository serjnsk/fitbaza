# fitbaza MVP · вариант «Strava»

Кликабельный прототип полного объёма MVP (см. [`03-mvp-and-roadmap.md`](../docs/03-mvp-and-roadmap.md)) в светлой оранжевой стилистике — референс Strava, плоский визуальный язык без карточек и теней.

## 🔗 Прототип

**[Открыть прототип →](https://rawcdn.githack.com/serjnsk/fitbaza/mvp-strava-prototype/mvp-strava/index.html)**

Прямая ссылка на конструктор (ядро продукта): [constructor.html](https://rawcdn.githack.com/serjnsk/fitbaza/mvp-strava-prototype/mvp-strava/constructor.html)

Открывается в браузере, полностью кликабельно — данные демонстрационные (тестовый тренер, 6 клиентов, 3 программы), состояние сохраняется в `localStorage` браузера.

Конструктор (`constructor.html`) — точная копия дизайн-концепции `showcase/01-strava/trainer.html`, доведённая до полноценного MVP остальными восемью страницами в том же визуальном языке.

## Функции конструктора (по `02-функциональные-требования.md`, раздел CON)

**Составление**
- **CON-1** Создание программы вручную (свободный ввод) — строка блока редактируется как обычный текст
- **CON-2** Составление из упражнений базы — правая панель, вкладка «Упражнения», поиск + клик добавляет строку
- **CON-3** Составление из готовых блоков — вкладка «Блоки» той же панели, блок вставляется одним нажатием
- **CON-5** Ввод обычным текстом — «присед 5×3 80%» набирается прямо в строке, парсер на лету линкует к базе; нераспознанное остаётся текстом до ручной разборки
- **CON-8** Drag-and-drop — упражнения и целые блоки перетаскиваются (иконка-хват слева у каждой строки/блока)
- **CON-4** Копирование предыдущей недели как основа новой — кнопка «Копия прошлой недели» в шапке недели

**Назначение**
- **CON-9** Назначение одному клиенту — кнопка «Назначить» в топбаре открывает шторку
- **CON-10** Массовое назначение — та же шторка позволяет отметить нескольких клиентов сразу, с превью их персональных максимумов

**Копирование и перенос**
- **CON-13** Перетаскивание тренировок между днями — drag день-в-день в полосе недели
- **CON-14** Перенос целой недели — тот же принцип на уровне недели

**Расчёт нагрузки**
- **CON-16** Автоматический расчёт рабочего веса от 1/3/5ПМ — пишешь «80 %», справа сразу килограммы под выбранного в топбаре атлета
- **CON-17** Автообновление процентов после нового ПМ — вес пересчитывается от актуального максимума без ручного вмешательства

**Шаблоны (TPL)**
- **TPL-1** Свои блоки с папками (разминки / силовые / комплексы / заминки) — вкладка «Тренировки» правой панели
- **TPL-2** Библиотека всех уровней — та же панель источников
- **TPL-3** Быстрое составление из шаблонов — кнопка «Из шаблонов» в шапке недели, вставляет сразу неделю

**Сознательно не реализовано в этой версии:** CON-6 (импорт из Excel / Sheets / CSV) и CON-11 (групповая программа с индивидуальными правками по атлету) — оба отмечены как вне MVP в `03-mvp-and-roadmap.md`. Таймер (TMR-1…4) — тоже вне MVP: формат комплекса (EMOM, AMRAP…) сохраняется как текст в блоке, отсчёт времени не реализован нигде в прототипе.

## Технически

Статические HTML-страницы без сборки, общие `assets/data.js` (доменная модель), `assets/ui.js` (навигация/топбар/тосты/модалки/графики) и `assets/pages.css` (компоненты страниц, которых нет в исходной дизайн-концепции). `constructor.html` использует `assets/trainer.js`, `assets/base-trainer.css`, `assets/theme-01-strava.css` — без изменений, byte-in-byte как в `showcase/01-strava/trainer.html`.
