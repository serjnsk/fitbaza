# 05 — Открытые вопросы

Решения, которые нужно принять до старта или на ранних этапах разработки. Каждый вопрос имеет ID (OQ-N); при принятии решения фиксируем ответ прямо здесь и переносим следствия в требования.

## OQ-1. Название продукта

Рабочее название репозитория — «fitbaza». Нужно утвердить название, домен и имена в App Store / Google Play.

## OQ-2. Десктоп тренера в MVP

> ✅ **Решено (август 2026): Вариант A.** Веб-версия конструктора для тренера входит в MVP — это критически важно: работа тренера по составлению программ почти всегда идёт с компьютера. Мобильные приложения — для всех ролей, телефон тренер использует в зале.

<details><summary>Исходные варианты</summary>

- **Вариант A (принят):** мобильные приложения для всех + веб-версия конструктора для тренера. Тренеры массово пишут программы с компьютера (так работает TRNR), а телефон используют в зале.
- **Вариант B (отклонён):** только мобильные приложения, десктоп — этап 2. Быстрее выйти, но рискуем проиграть конструктору TRNR в самом частом сценарии.

</details>

## OQ-3. Технологический стек

Не зафиксирован. Требования, влияющие на выбор: iOS + Android + веб одним ресурсом, local-first оффлайн с синхронизацией (NFR-3), drag-and-drop, фоновый таймер с заблокированным экраном, загрузка/стриминг видео. Кандидаты: Flutter или React Native + серверная часть с sync-механизмом (например, PowerSync/ElectricSQL/самописный) — решить с разработчиком до старта.

## OQ-4. Платёжный провайдер и юрисдикция

Рынок старта — РФ (конкурент — TRNR). Для приёма платежей клиентов и выплат тренерам (PAY-7) нужно выбрать провайдера (ЮKassa, CloudPayments, Робокасса и т.п.) и юридическую схему: платформа как посредник (агентская схема) или прямые платежи клиент → тренер. Это влияет на этап 2, решить заранее.

## OQ-5. Оплата через App Store / Google Play

> ✅ **Решено (август 2026).** Оплата подписки на сервис (PAY-8) доступна тренерам только в веб-версии — это обходит комиссию App Store. Платежи клиентов тренеру (PAY-1…PAY-7) не входят в MVP, поэтому вопрос для них будет решаться на этапе 2.

## OQ-6. Хранение и обработка видео

Своя загрузка видео без YouTube/VK (VID-1) означает: объектное хранилище (S3-совместимое), транскодинг, CDN. Оценить стоимость на тренера и заложить лимиты в тарифы.

## OQ-7. Персональные и медицинские данные

> ✅ **Решено (август 2026).** Консультация проведена, вопросов по схеме работы с персональными и медицинскими данными нет. Требования 152-ФЗ (локализация, согласия на обработку) учитываем при реализации профиля (PRO-3).

## OQ-8. Модель монетизации платформы

TRNR берёт от 1000 ₽/мес в зависимости от числа клиентов. Наши варианты: подписка тренера по числу клиентов, комиссия с платежей клиентов, гибрид. Гипотеза для проверки на этапе 2.

## OQ-9. Стартовая база упражнений

Откуда берём контент базы (EX-1): лицензирование, собственная съёмка, ИИ-генерация описаний (AI-1) + постепенное наполнение видео тренеров? Влияет на первое впечатление от MVP.

## OQ-10. Распознавание текста тренировок

CON-5/CON-7 (ввод текстом) и TMR-1 (таймер из «EMOM 12») требуют парсер тренировочной нотации. Решить: правила/регулярки на старте или LLM-парсинг (дороже, но гибче). Для MVP таймер можно ограничить фиксированными форматами.
