# 03 — MVP и роадмап

Все функции из [02 — Функциональные требования](02-functional-requirements.md) распределены по трём этапам. Логика приоритизации:

- **Этап 1 — MVP.** Скелет продукта (визуал, конструктор, анкеты тренера и клиента, календарь) + полная скорость тренера — ключевое УТП: текстовый ввод, шаблоны, массовые операции, групповые программы. Минимальный рабочий цикл: тренер составил программу → клиент выполнил и записал результат → тренер увидел.
- **Этап 2 — Монетизация.** Платежи (продукт начинает зарабатывать), полный оффлайн, таймер, видео и обратная связь, анкеты и уведомления.
- **Этап 3 — Рост и экосистема.** Курсы, лидерборды, бренд тренера, ИИ, интеграции — функции удержания и роста среднего чека.

---

## Этап 1 — MVP

**Цель:** тренер ведёт реальных клиентов в приложении и отказывается от Google-таблиц. Проверяем главную гипотезу — конструктор быстрее и удобнее всего, чем тренер пользуется сейчас.

### Скелет (обязательное ядро)

| Модуль | Требования | Состав в MVP |
|---|---|---|
| Визуал | — | Дизайн-система (референс — HWPO), тёмная/светлая тема не обязательна |
| Регистрация | REG-1, REG-2, REG-3 | Ссылка тренера + вход по номеру телефона |
| Конструктор: составление | CON-1…CON-8 | Вручную, из базы упражнений, из готовых блоков, копия недели, обычным текстом, вставка из заметок, импорт Excel/Google Sheets/CSV, drag-and-drop |
| Конструктор: назначение | CON-9, CON-10, CON-11 | Одному клиенту, массовое назначение, групповая программа с индивидуальными правками |
| Конструктор: копирование | CON-12…CON-15 | Массовое копирование, перенос недель, сдвиг программы на +3/+7/+14 дней |
| Конструктор: расчёт нагрузки | CON-16, CON-17 | Рабочие веса от 1ПМ/3ПМ/5ПМ (проценты → кг), автообновление после нового рекорда |
| Шаблоны | TPL-1, TPL-2, TPL-3 | Собственные блоки с папками, библиотека шаблонов: упражнения → блоки → тренировки → недели → программы |
| Импорт из TRNR | INT-2 | Перенос данных тренера с прямого конкурента — сильно помогает на старте забирать тренеров |
| База упражнений | EX-1, EX-2 (без видео), EX-3 | Стартовая база + свои упражнения + гибкие показатели (заложить в модель данных сразу, даже если UI простой) |
| Календарь | CAL-1 (уровни неделя/тренировка) | Неделя и тренировка; циклы — этап 3 |
| Выполнение клиентом | CLI-1, CLI-2 | Просмотр тренировок, запись весов/повторов/ПМ/результатов |
| Оффлайн клиента | CLI-3 | Чтение программы и запись результатов без сети (архитектура local-first с первого дня — NFR-3) |
| Профиль спортсмена | PRO-1, PRO-2, PRO-4 (1/3/5ПМ), PRO-6 | Основное, антропометрия, ПМ, история показателя с графиком |
| Коммуникация | COM-1, COM-2, COM-3 (без видеоответов), COM-4 | Комментарии к тренировке и упражнению, ответ тренера |
| Админ | ADM-1, ADM-2, ADM-3 | Минимальные списки тренеров и клиентов |
| Платформы | NFR-1, NFR-2, NFR-3, NFR-4 | Мобильные приложения iOS/Android + **веб-версия конструктора для тренера** (составление программ почти всегда идёт с компьютера) |

### Сознательно НЕ входит в MVP

Платежи (первым тренерам даём бесплатно/вручную), таймер, видеозагрузка, анкеты, уведомления, курсы, лидерборды, ИИ, интеграции, бренд тренера.

**Критерий готовности MVP:** 5–10 живых тренеров ведут своих клиентов неделями без возврата к таблицам.

## Этап 2 — Монетизация (v1.0)

**Цель:** продукт зарабатывает; клиентский опыт добирает таймер, видео и анкеты.

### Платежи

- PAY-1 — блокировка доступа без оплаты
- PAY-2 — разовые, подписки, автопродление, промокоды, пробный период
- PAY-3 — несколько тарифов тренера (онлайн/оффлайн/группы)
- PAY-4 — история и просроченные платежи
- PAY-5 — автоограничение доступа по настройке тренера
- PAY-6 — продление без оплаты по уважительной причине
- PAY-8 — подписка тренера на сервис (оплата только в веб-версии — обход комиссии App Store)

### Оффлайн полностью

- CLI-4 — тренер создаёт/редактирует без сети
- CLI-5 — автосинхронизация всех изменений

### Видео и обратная связь

- VID-1, VID-2 — видеобиблиотека тренера, привязка к упражнению/тренировке/программе
- VID-3 — видео техники от спортсмена
- VID-4 (частично) — просмотр, пауза, замедление, текстовый комментарий (рисование и голос — этап 3)
- COM-5 — приватные заметки тренера

### Мониторинг и удержание

- SUR-1, SUR-2, SUR-3 — еженедельные анкеты по шаблонам тренера
- NTF-1, NTF-2 — уведомления + полное управление автоматизациями
- PRO-3, PRO-5, PRO-7 — медицина, цели, статистика в профиле клиента
- TMR-1…TMR-4 — интегрированный таймер: EMOM и интервалы из текста тренировки, звук и вибрация, большие цифры, работа с заблокированным экраном

## Этап 3 — Рост и экосистема (v2.0)

**Цель:** рост среднего чека тренера, виральность, удержание.

### Продажи тренера

- CRS-1, CRS-2, CRS-3 — курсы (видео, текст, тренировки, документы, тесты, задания, чек-листы; разово или подписка)
- PAY-7 — взаиморасчёты и вывод средств на счёт тренера
- BRD-1, BRD-2 — бренд тренера и публичная страница с отзывами и кнопкой «Начать тренировки»

### Вовлечение клиентов

- LB-1, LB-2, LB-3 — лидерборды с делением по категориям и полным отключением
- LB-4 — ачивки (аналог FatSecret)
- INT-1 — Apple Health и носимые устройства (Whoop и др.)

### Профессиональная периодизация

- CAL-1 (полностью) — год/сезон/макроцикл/мезоцикл/микроцикл
- CAL-2 — отметки: соревнования, матчи, сборы, тестирования, восстановление, отпуск, травмы, контрольные
- PRO-4 (полностью) — пользовательские тесты тренера

### ИИ и видео

- AI-1, AI-2, AI-3 — генерация описаний, фото упражнений, программ
- VID-4 (полностью) — рисование поверх кадра, голосовые комментарии
