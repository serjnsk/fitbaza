# fitbaza — приложение для тренеров

Внутренняя документация по разработке приложения для ведения тренировок: для тренеров по кроссфиту, тренажёрному залу и смежным видам спорта.

> «fitbaza» — тестовое название на период разработки; финальное название утверждается перед запуском (решение OQ-1).

Репозиторий — единый источник требований для разработчика и дизайнера. Все идеи и заметки основателя собраны, структурированы и приоритизированы здесь.

| [02 — Функциональные требования](docs/02-functional-requirements.md) | Полный каталог функций по модулям с ID требований (единый консолидированный документ) |

## Как пользоваться

- **Разработчику:** начинать с [02 — Функциональные требования](docs/02-functional-requirements.md) и [03 — MVP и роадмап](docs/03-mvp-and-roadmap.md). Область MVP — только то, что помечено этапом **MVP**.
- **Дизайнеру:** начинать с [01 — Обзор продукта](docs/01-product-overview.md) и [04 — Конкуренты](docs/04-competitors.md) (референс по дизайну — HWPO Training).
- Каждая функция имеет стабильный ID (например `CON-3`) — используйте его в задачах, макетах и обсуждениях.
