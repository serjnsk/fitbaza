# Прототипы

> **Передаёте работу другому исполнителю?** Начните с [HANDOVER.md](HANDOVER.md) —
> что сделано, почему сделано так и что осталось открытым.

Интерактивные прототипы экранов. Папка самодостаточная: файлы документации
(`docs/`, `mkdocs.yml`, `README.md`) отсюда не затрагиваются, на сборку сайта
прототипы не влияют.

| Прототип | | |
|---|---|---|
| **Конструктор тренировок** — экран CON в пяти визуальных направлениях | [описание](constructor-styles/) | [▶︎ открыть](https://raw.githack.com/serjnsk/fitbaza/prototype/constructor-styles/prototypes/constructor-styles/index.html) |
| **Экраны в четырёх стилистиках** — конструктор тренера и тренировка клиента × 4 визуальные гипотезы | [описание](screens/) | [▶︎ открыть](https://raw.githack.com/serjnsk/fitbaza/prototype/screens-4-styles/prototypes/screens/index.html) |
| **Пять стилистик, живые** — те же два экрана × 5 визуальных языков, каждый работает: дни переключаются, строки разбираются, подходы отмечаются | [описание](showcase/) | [▶︎ открыть](https://raw.githack.com/serjnsk/fitbaza/prototype/screens-4-styles/prototypes/showcase/index.html) |

Каждый прототип — статические HTML, CSS и JS без сборки. Новые кладём соседними
папками по тому же принципу.
