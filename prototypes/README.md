# Прототипы

Интерактивные прототипы экранов. Папка самодостаточная: файлы документации
(`docs/`, `mkdocs.yml`, `README.md`) отсюда не затрагиваются, на сборку сайта
прототипы не влияют.

папками по тому же принципу.
