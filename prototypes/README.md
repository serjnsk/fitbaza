# Прототипы

Интерактивные прототипы экранов. Папка отдельная и самодостаточная: файлы
документации (`docs/`, `mkdocs.yml`) отсюда не затрагиваются, на сборку сайта
прототипы не влияют.

Каждый прототип — статические HTML, CSS и JS без сборки. Открывать локально
двойным кликом по `index.html` внутри папки прототипа.

| Папка | Что это |
|---|---|
| `constructor-styles/` | Конструктор тренировок (модуль CON) в пяти визуальных направлениях |

Новые прототипы кладём соседними папками по тому же принципу.
