# Handoff: Fitbaza — конструктор тренировок (веб, десктоп)

## Overview
Рабочее пространство тренера: он собирает тренировку клиенту на неделю. Слева навигация по продукту, сверху бредкрамбы + выбор клиента, в центре «дорожка недели» → выбранный день → блоки с упражнениями, справа библиотека упражнений/блоков/тренировок. Ключевая идея ввода: тренер может просто печатать строку «Присед 5×3 80%», библиотека — вспомогательная.

## About the Design Files
Файлы в этом бандле — **дизайн-референсы, сделанные в HTML**. Это прототипы, показывающие задуманный вид и поведение, **а не продакшн-код для копирования**. Задача — **воспроизвести эти дизайны в существующем окружении целевого проекта** (React / Vue / Svelte / что используется), по его сложившимся паттернам и библиотекам. Если окружения ещё нет — выбрать подходящий стек и реализовать там.

Технически `.dc.html` — это самодостаточный HTML, который открывается в браузере; разметка лежит внутри тега `<x-dc>`, стили — инлайновые, `support.js` — только рантайм превью. Читать нужно разметку внутри `<x-dc>`, `support.js` в продакшн не переносится.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы — финальные, воспроизводить пиксельно (с адаптацией под токены кодовой базы, если они уже есть). Интерактив в прототипе не запрограммирован: это статичное состояние, поведение описано ниже словами.

## Interactions & Behavior
Прототип статичен; ожидаемое поведение:
- **Week track**: клик по дню → загрузка его блоков в холст (день становится лаймовым, предыдущий белым). Ширина дня пересчитывается из количества упражнений. Дни отдыха кликабельны — превращаются в тренировочный день при добавлении блока. Drag&drop дня на другой день = перенос/копирование тренировки. Стрелки «←/→» листают недели.
- **Ввод упражнения**: главный путь — свободный текст в dashed-инпуте с парсингом («Присед 5×3 80%» → упражнение + 5 подходов × 3 повтора при 80% 1ПМ, вес считается от 1ПМ выбранного клиента). Неразобранная строка остаётся текстовой заметкой; матч по названию — из базы упражнений с автодополнением.
- **Проценты и веса**: селектор клиента в топбаре меняет расчёт всех `%` → кг по 1ПМ этого клиента (в макете 80% = 152 кг, т.е. 1ПМ 190 кг; округление до 1 кг, опционально до шага диска 2.5 кг).
- **Drag&drop**: упражнения переставляются внутри блока и между блоками за хэндл `⠿`; карточки из библиотеки перетаскиваются в блок; блоки переставляются за шапку.
- **Hover**: у нейтральных пилюль/строк фон `#F6F6F2` → `#F1F1EC`; у круглых кнопок → `#E4E4DC`; `✕` → `#111110`; переход `background-color 120ms ease`.
- **Focus**: инпуты получают `border-color: #D6F84C` (сплошная 1.5px) вместо dashed.
- **«Назначить»**: публикует неделю клиенту, статус-чип «ЧЕРНОВИК» → «НАЗНАЧЕНО» (фон `#D6F84C`, текст `#4E5C15`).
- **Автосохранение**: кнопка «Сохранить» — явное действие; статус черновика показывать в топбаре.
- Адаптив: ниже ~1400px библиотеку сворачивать в правый оверлей-дровер (340px) с круглой кнопкой вызова в топбаре; week track при нехватке ширины скроллится горизонтально, сохраняя пропорции flex.

## State Management
- `program`: `{ id, title, weeksTotal, currentWeekIndex, status: 'draft' | 'assigned' }`
- `week`: `{ startDate, days: Day[] }`, `Day: { date, weekday, title | null, isRest, blocks: Block[] }`
- `Block`: `{ id, order, title, type: 'warmup' | 'strength' | 'metcon' | 'gymnastics' | 'cooldown', restSeconds, note, exercises: Exercise[] }`
- `Exercise`: `{ id, order, exerciseRefId | null, rawText, nameRu, nameEn, equipment, sets, reps, percentOf1RM | null, weightKg | null, durationSec | null, calories | null }`
- UI-состояние: `selectedDayDate`, `selectedExerciseId`, `libraryTab`, `librarySearch`, `activeClientId`, `dragging: { type: 'exercise' | 'block' | 'day', id }`.
- Производные значения: ширина дня (`exerciseCount`), заполненность бара, `weightKg = round(client.oneRM[exercise] * percent)`, счётчики блоков/упражнений в шапках.
- Данные: список клиентов с их 1ПМ, база упражнений (31), шаблоны (21), программы (3).
