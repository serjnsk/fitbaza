# Fitbaza — design handoff

Два самодостаточных HTML-файла со статичной эталонной вёрсткой. Открываются в браузере, без сборки и без JS.

- `fitbaza-constructor-warm.html` — десктопный конструктор тренировки у тренера (1600×1000).
- `fitbaza-client-mobile-warm.html` — мобильное приложение клиента, 3 экрана рядом (390×844 каждый): план дня, запись подхода, отдых между подходами.

## Как читать
Токены (цвета, шрифты, радиусы, тени, сетка) перечислены в комментарии в начале каждого файла — переносите их в переменные/тему вашего фреймворка. Вся стилизация инлайновая, чтобы разметка и оформление читались вместе; при реализации выносите в компоненты и классы.

## Что важно сохранить
- Тёплая бумажная палитра: фон `#FBF7F1`, карточки белые, единственный акцент — оранжевый `#F5511E`.
- Пилюли (radius 999px) для всех кнопок, табов, чипов, аватаров.
- Моноширинный `IBM Plex Mono` для всех чисел: веса, подходы, таймеры, счётчики, служебные подписи капсом.
- Крупные плотные заголовки (letter-spacing −1px), спокойный вторичный текст.
- Тёмная панель `#1E1B18` — только для «здесь и сейчас»: активный блок, экран отдыха.
- Иконки в файлах — текстовые заглушки (◻ ◯ ◈ ☰ ⧉ ⌕ ✓ ▶ ✎). Замените на нормальный icon set.
- Видео-техника, аватары — серые плейсхолдеры, ждут реальных ассетов.

## Состояния, которые видны в макетах
- упражнение: обычное / активное (акцентная рамка) / выполненное (перечёркнутое, opacity)
- подходы: выполнен (тёмный) → текущий (акцентная обводка) → предстоящий (серый) → «+ подход» (пунктир)
- день недели: обычный / активный (акцент) / отдых (приглушённый)
- библиотека: упражнение доступно (+) / уже добавлено в блок (✓, акцентный фон)
